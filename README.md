# 찌똘현 물놀이 대시보드 — 전국판

전국 주요 해수욕장의 수온·파고·바람·강수·자외선과 아기 물놀이 추천도를 모바일에서 비교하는 PWA입니다.
현재는 해수욕장 기준으로 대시보드가 구성되어있습니다.

바다 외에 물놀이 스팟 업데이트 예정(시간이 난다면..?)

## 주요 기능
- 전국 지역별 필터 및 검색
- 추천 TOP 3와 물놀이 점수
- 수온, 파고, 바람, 강수, UV
- 현재 위치 기준 거리순
- 즐겨찾기
- 3일 수온 변화
- 네이버 지도 연결
- 국립수산과학원 냉수대·실측 수온 바로가기
- 모바일 홈 화면 설치(PWA)

## 주의
해양 예측 모델값은 연안과 얕은 수심에서 실제 관측값과 차이가 날 수 있습니다.
현장 안전요원 안내, 입수 통제, 이안류·풍랑·태풍 특보 및 공식 냉수대 정보가 항상 우선입니다.

## 대시보드 데이터 출처
1. Open-Meteo Marine API
- 바다 수온
- 파고
- 파주기
- 3일 수온변화
2. 국립수산과학원 실시간 해양수산환경 관측시스템
- API X, 공식 사이트 크롤링
- 관측소 별 실제 표층,중층,저층 수온
- 냉수대 수온정보, 이상수온 특보
- 관측소 지도, 과거 관측자료
3. 국립해양조사원 바다누리
- 조석, 조류, 해양관측, 파고와 해양예보
4. 지도서비스
- IpenStreetMap 지도 타일 사용 / 네이버 지도 링크

## 추천 점수 산정
- 수온이 24℃ 이상인지
- 파고가 0.5m 이하인지
- 바람이 너무 강하지 않은지
- 비가 오는지
- 자외선이 지나치게 높은지

공식 안전등급이나 입수 가능 여부를 의미하지는 않습니다. 현장 안전요원 안내, 입수 통제, 이안류·풍랑·태풍 특보가 항상 우선입니다.
