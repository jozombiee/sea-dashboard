# 우리 가족 바다 3.0 — 전국 바다비서

전국 주요 해수욕장의 해양·기상 예보를 모바일에서 비교하는 GitHub Pages용 PWA입니다.

## 데이터 출처
### 화면에 자동 반영
- Open-Meteo Marine API
  - 해수면 수온
  - 파고
  - 파주기
- Open-Meteo Weather Forecast API
  - 10m 바람
  - 강수
  - 일 최대 UV 지수

### 공식 사이트에서 최종 확인
- 국립수산과학원 실시간 해양수산환경 관측시스템
  - 관측소 실측 수온
  - 냉수대·고수온 등 이상수온 특보
- 국립해양조사원 바다누리
  - 조석, 조류, 파고 등 종합 해양정보

### 지도
- OpenStreetMap 지도 타일
- 네이버 지도 검색 링크

## 3.0 기능
- 가족·물놀이·서핑·스노클링·낚시 모드별 추천 점수
- 전국 지도
- 지역별 필터, 검색, 거리순
- 추천 TOP 3
- 이번 주말 추천
- 3일 수온 변화
- 즐겨찾기
- 사이트 방문 시 즐겨찾기 저수온 브라우저 알림
- 모바일 홈 화면 설치

## 중요한 제한
- 표시 수온은 해변의 현장 실측값이 아니라 해양 수치예보 모델값입니다.
- 연안과 얕은 수심에서는 실제 수온 및 파고와 차이가 날 수 있습니다.
- GitHub Pages에는 서버가 없으므로 사이트를 닫은 상태에서 보내는 백그라운드 푸시 알림은 제공하지 않습니다.
- 현장 입수 통제, 안전요원 안내, 이안류·풍랑·태풍 특보와 공식 냉수대 정보가 항상 우선입니다.

## 배포
저장소 최상위의 기존 파일을 이 ZIP의 파일로 교체한 후 Commit하면 GitHub Pages가 자동 재배포됩니다.
